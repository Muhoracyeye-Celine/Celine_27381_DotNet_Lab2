# Celine_27381_DotNet_Lab2

C# Windows Forms assignment with four forms:

- Login
- Choose Program
- Bicycle Rental
- Mushroom Identification

## Features

- Login accepts any nonempty username and password.
- Bicycle rental calculates payment using hourly rates.
- Mushroom identification uses at most three questions.
- Input validation and Back, Logout, and Exit buttons.

## How to Run

1. Download or clone this repository.
2. Open the solution (.sln) file in Visual Studio.
3. Ensure .NET 10 and the .NET desktop development workload are installed.
4. Press F5 to run.
